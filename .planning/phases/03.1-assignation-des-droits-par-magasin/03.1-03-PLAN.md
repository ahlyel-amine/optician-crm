**A. `dialogues.tsx` — `DialogueAjoutMagasin`.**

Bâti comme ses quatre voisins : `AlertDialog`, `AlertDialogCancel` libellé par la constante
`RETOUR` du fichier, `AlertDialogAction` pour confirmer. **Pas** de `bg-destructive` : ajouter
un magasin n'est pas destructif. Le libellé de confirmation est `Ajouter le magasin`.

    export type ProprietesDialogueAjoutMagasin = {
      ouvert: boolean;
      nomDuMagasin: string;
      prenom: string;
      /** Les lignes accordées uniformément — celles qui s'étendraient. */
      uniformes: number;
      /** Les lignes réglées magasin par magasin — celles qui ne s'étendront jamais. */
      personnalisees: number;
      surRetour: () => void;
      surConfirmation: (reappliquer: boolean) => void;
    };

Le choix est un **groupe de boutons radio natifs** dans un `<fieldset>` avec une `<legend>`,
pas deux boutons de confirmation côte à côte. Trois raisons : trois boutons dans un pied de
dialogue se lisent comme trois actions de poids égal alors que l'une est le défaut ; une
radio pré-sélectionnée **est** la façon d'offrir un défaut, ce que le CONTEXT exige
littéralement ; et l'état sélectionné reste lisible avant la confirmation. Radio natif et
non composant shadcn : `radio-group` n'est pas installé, et l'écran a déjà le précédent du
`<select>` natif de `Statut` (7.3 A).

L'état de la radio est un `useState` **interne au dialogue**, initialisé à `true`
(réappliquer), et réinitialisé à l'ouverture — sans quoi un `Retour` puis une réouverture
proposerait le choix précédent au lieu du défaut.

La copie, en constantes nommées du module comme ses voisines. Voix de 9.2 : vouvoiement,
présent, aucune excuse. Les deux phrases chiffrées sont **le cœur de la décision 2** et
sont non négociables :

> ### Ajouter le magasin Californie au compte de Karim ?
>
> ( • ) **Réappliquer les droits existants**
>       Les 8 droits accordés dans tous ses magasins le seront aussi à Californie. Les 2
>       droits réglés magasin par magasin ne le seront pas : Californie démarre sans eux.
>
> (   ) **Démarrer sans aucun droit**
>       Karim verra Californie, mais n'y aura aucun droit. Vous les accorderez ensuite.
>
> `[ Retour ]`   `[ Ajouter le magasin ]`

Accorder les deux phrases au singulier quand le compte vaut 1 — `Le droit accordé […] le
