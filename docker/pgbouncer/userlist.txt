; PgBouncer auth file — LOCAL DEVELOPMENT ONLY.
;
; The password below is the development-only credential created by
; docker/postgres/init/00-databases.sql. It grants access to nothing but a throwaway
; local container whose port is published on 127.0.0.1 only. It is not a secret, and no
; real credential may ever be committed to this file.
;
; It is stored in plain text on purpose. PgBouncer can authenticate a *client* from a
; stored SCRAM verifier, but it cannot use that verifier to authenticate itself to
; PostgreSQL — SCRAM verifiers are not password-equivalent for outbound authentication.
; With the plain password here, PgBouncer computes the SCRAM exchange for the client and
; still has what it needs to log in to the server.
;
; In production, do not ship this file. Use auth_query against pg_shadow instead:
;   auth_user = pgbouncer_auth
;   auth_query = SELECT usename, passwd FROM pg_shadow WHERE usename = $1
; so credentials live only in PostgreSQL and a new client role needs no PgBouncer reload.
